# Security Policy

## Reporting

Please report suspected vulnerabilities privately through GitHub Security Advisories when enabled, or through AliceLabs' published business contact channel. Do not post exploit details, credentials, private media or customer property data in public issues.

Include the affected version, component, reproduction steps and impact.

## Data handling

Property photos, generated media, voice recordings, floor plans and contact details may be sensitive. Do not commit customer assets or API credentials. Provider keys must remain in server-side secrets, never browser bundles or public environment variables. Clearly disclose external AI processing and retention behavior wherever media leaves the user's device or server.

Generated visuals must not be represented as documentary evidence of a property's actual condition or features.
